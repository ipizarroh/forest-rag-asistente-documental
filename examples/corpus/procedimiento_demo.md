# Documento ficticio de demostración — ForestRAG

Material original creado exclusivamente para probar software. No describe procedimientos reales de ARAUCO ni habilita trabajos en maquinaria. No debe aplicarse en una faena.

## Registro de mantenimiento
En este ejemplo ficticio, una orden de mantenimiento registra el identificador del equipo, la fecha de solicitud, la descripción de la observación, la prioridad declarada y la persona responsable del seguimiento. El cierre conserva una evidencia y la fecha de revisión. Esta descripción sólo sirve para probar recuperación de campos documentales.

## Planificación documental
La versión vigente de un documento de planificación se identifica mediante un código, un número de versión y una fecha. El registro documental conserva el enlace a la fuente y el nombre del responsable de la revisión. Una copia histórica debe identificarse como histórica.

## Inventario de demostración
La tabla ficticia de inventario incluye código de producto, unidad de medida, ubicación y fecha de actualización. No contiene cantidades reales ni datos de una empresa. Para confirmar existencias, el caso de ejemplo remite al registro autorizado más reciente.
