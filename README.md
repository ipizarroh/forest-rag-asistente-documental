# ForestRAG — Asistente Documental Forestal

Proyecto personal de portafolio de Ignacio Pizarro Hurtado. Sin afiliación, patrocinio ni aprobación de ARAUCO.

Prototipo en desarrollo para consulta documental forestal con Python, recuperación vectorial, trazabilidad de fuentes y evaluación reproducible.

## Estado inicial

Repositorio creado. Implementación y pruebas en preparación. La existencia del repositorio no acredita un RAG completo ni uso industrial.

No contiene documentos internos de empresas ni información de otros proyectos. No sustituye procedimientos oficiales ni decisiones de profesionales autorizados.
